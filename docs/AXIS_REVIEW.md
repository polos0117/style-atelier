# style-atelier 화풍 조립 축 개편 검토안

- 작성일: 2026-11-10
- 문서 버전: 1.0
- 상태: 검토안 — 저장소 반영 전
- 목적: 화풍 문구를 담당 범위별로 조립하고, 실제 이미지 생성으로 각 부품과 조합의 효과를 비교한다.

## 1. 권장 방향

기존 다섯 축은 유지하고, 축의 이름과 담당 범위를 다음과 같이 정리한다.

**방향 · 얼굴 표현 · 렌더링·채색 · 조명·색조 · 이펙트**

축을 더 늘리기보다, 다섯 축 안에서 문구의 중복과 충돌을 줄이고 실험 방법을 정교하게 만든다. 검토 당시 활성 부품과 기본 호환 규칙으로 조립 가능한 조합은 8,832개였다. 조합 수는 부품과 호환 규칙이 바뀌면 달라진다.

구조의 목표는 **문구를 중복 없이 교체할 수 있게 만드는 것**이다. 한 축을 바꿨을 때 이미지에서도 그 부분만 바뀐다고 전제하지 않는다. 나라 이름에 따라 얼굴이나 채색 느낌이 함께 달라지는 현상은 축 사이의 상호작용으로 기록한다.

## 2. 축별 담당 범위

| 축 | 맡는 것 | 넣는 말 | 다른 곳으로 보내는 말 | 권장 문장 꼴·길이 |
|---|---|---|---|---|
| 방향 | 문화권·시각적 전통·장르·작품 용도 | Korean, Japanese, MMORPG, gacha, character artwork, key art | 2D·3D·CGI·사진 같은 표현 방식, 붓질, 얼굴, 조명, 품질 수식어 | 나라·장르·작품 용도를 조합한 명사구 한 문장. 12단어 이내 |
| 얼굴 표현 | 얼굴의 사실성·단순화·이상화 정도 | drawn, illustrated, idealised, simplified anatomical structure, realistic facial structure | 실제 나이, 얼굴 크기, 눈·코·입 형태, 인종, 화장, 채색 재료, 조명 | A/An으로 시작하는 얼굴 표현 한 문장. 25단어 이내 |
| 렌더링·채색 | 표현 방식·부피감·칠하는 재료·붓·선·가장자리·표면 질감·재질 구분 | digital painting, oil glazes, cel shading, 3D rendering, photographic rendering, brushwork, linework, edge control, material treatment | 문화권·장르, 캐릭터 생김새, 광원 방향, 전체 노출·채도·색온도 | 표현 방식이나 재료 이름으로 시작. 40단어 이내 |
| 조명·색조 | 광원 방향·크기·세기, 명암, 노출, 채도, 색온도, 화면상 하이라이트의 세기·범위 | key light, rim light, shadow contrast, exposure, saturation, colour balance, highlights | 붓질·페인트 질감, 표면 자체의 무광·유광 성격, 장식적인 발광·입자 | `Light:` 뒤에 붙는 소문자 구. 35단어 이내 |
| 이펙트 | 발광 번짐·블룸·반짝임·입자·장식적 후광의 종류·양·위치 | bloom, sparkles, particles, halo와 양·위치 표현 | 기본 조명, 캐릭터 고유색, 발광 장치 자체의 디자인 | 짧은 한 문장. 미지정이면 비우고, 없음이면 해당 효과를 avoid로 억제 |

단어 수는 작성 기준이다. 문장을 억지로 압축하기보다 담당 범위와 모순 여부를 우선한다.

### 2.1 방향과 표현 방식

방향에는 그림의 문화적·장르적 맥락과 용도를 둔다. 2D·3D·CGI·사진처럼 제작·표현 방식을 지정하는 말은 렌더링·채색에 모은다.

- 방향 예: `Japanese fantasy game key art.`
- 방향 예: `Korean MMORPG character artwork.`
- 유화·셀·3D·사진적 표현: 렌더링·채색에서 선택.

나라 이름은 비교하려는 요소이므로 유지한다. 다만 그림의 문화적 표현 맥락과 캐릭터의 인종·세계관을 구별한다. 인종과 세계관은 캐릭터·세계 설계에 둔다.

`2.3D` 같은 명칭은 표시 이름이나 검색 태그로 남길 수 있다. 실제 생성 문장에서는 그린 형태가 드러나는 정도, 부피감, 표면 세부 묘사처럼 관찰할 수 있는 특징으로 풀어 쓴다.

### 2.2 얼굴 표현과 캐릭터 설계

같은 캐릭터의 화풍을 비교할 때는 실제 나이와 얼굴 크기도 고정 조건으로 둔다.

| 표현 | 담당 |
|---|---|
| 작은 얼굴, 큰 눈, 둥근 턱, 작은 코 | 캐릭터 설계 |
| 성인, 20대 후반 | 캐릭터 설계·공통 조건 |
| 이상화된 얼굴, 단순화한 얼굴 구조, 사실적인 해부 구조 | 얼굴 표현 |
| 부드러운 음영, 피부 미세질감 | 렌더링·채색 |
| 홍조, 아이라인 | 캐릭터 화장 |

애니 표현에 맞춰 눈 크기까지 바꾸는 실험은 가능하다. 다만 생김새의 변형을 허용한 비교임을 별도로 기록한다.

### 2.3 표면과 조명

- 표면 자체의 무광·유광·거칠기와 재질 표현: 렌더링·채색.
- 광원의 방향·크기·세기와 전체 명암·색조: 조명·색조.
- 화면에서 원하는 하이라이트의 세기·범위: 조명·색조에 명시적으로 배정.
- 장식적인 발광 번짐·블룸·입자·후광: 이펙트.

하이라이트는 표면과 조명의 영향을 함께 받으므로 결과까지 완전히 독립적이라고 보지 않는다. 같은 특성을 여러 축에서 되풀이해 지시하는 것을 피한다.

## 3. 모든 축에 적용할 공통 규칙

| 규칙 | 적용 방법 |
|---|---|
| 한 가지 사실은 한 축에만 쓴다 | 단어 일치가 아니라 뜻 기준으로 중복을 점검한다. `matte surfaces`와 `restrained sheen`도 같은 성격을 반복 지정하는지 확인한다. |
| 부정 지시는 avoid에 둔다 | 부품 문장은 긍정적인 묘사로 작성하고, 부정 지시는 프롬프트의 제5칸 `CONSTRAINTS`에 모은다. |
| avoid도 부품과 함께 교체한다 | 선택한 부품의 avoid만 합친다. 부품을 바꾸면 이전 부품의 avoid도 빠져야 한다. |
| 부정문을 옮긴 뒤에도 충돌을 검사한다 | `never rendered`처럼 범위가 넓은 말은 피하려는 결과를 구체화한다. 위치만 옮겨도 다른 축과의 모순은 남을 수 있다. |
| 화가·작품·상표 이름을 쓰지 않는다 | 화풍을 설명하는 일반적인 표현으로 정의한다. |
| 한글 표시 이름과 문장을 맞춘다 | 유화·무광·파스텔·3D처럼 조합을 구별하는 핵심 이름은 실제 문구에 근거가 있어야 한다. |
| 바꾸면 판을 올린다 | 이전 판을 보존하고 새 판을 추가한다. 새 문구로 옛 이미지의 기록을 덮어쓰지 않는다. |
| 문구 관리와 결과 해석을 구별한다 | 문구가 분리돼 있어도 결과에서는 다른 특징이 함께 변할 수 있다. 이를 실험 기록에 남긴다. |

### 3.1 미지정과 없음

| 상태 | 의미 | 조립 방식 |
|---|---|---|
| 미지정 | 해당 효과를 추가로 지시하지 않음 | 이펙트 문장을 비움 |
| 없음 | 특정 장식적 효과를 억제하도록 지시함 | 해당 효과를 avoid에 명시 |
| 있음 | 종류·양·위치를 지정함 | 이펙트 문장을 조립 |

검토 당시 `fx/none`은 빈 문자열이었다. 따라서 기존 값은 실제로 미지정에 해당한다. 명시적인 없음을 도입할 때는 새 판을 만들고, 기존 판의 의미와 기록은 보존한다.

## 4. 기존 부품의 수정 방향

| 대상 | 문제 | 권장 수정 |
|---|---|---|
| 방향 · 고전 초상 | `classical oil-painting manner`에 재료가 포함됨 | 문화적 전통·작품 용도만 방향에 두고 oil은 렌더링·채색으로 이동 |
| 방향 · 일본 게임 페인팅 | painterly와 finished가 방향에 포함됨 | `Japanese fantasy game key art.`처럼 정리하고 painterly 특성은 렌더링·채색으로 이동 |
| 방향 · 판타지 페인팅 | Painterly가 방향에 포함되고 문화권이 미지정됨 | 문화권을 지정하거나 부품을 내리는 기존 제안을 검토하고, Painterly는 렌더링·채색으로 이동 |
| 방향 · 일본·한국 가챠 | clean과 2D가 방향에 포함됨 | 가챠 장르·문화권·작품 용도만 남기고 선의 정돈과 2D 표현은 렌더링·채색으로 이동 |
| 얼굴 · 일러스트형 | 2.3D와 전체 입체감 설명이 섞임 | 얼굴의 그린 느낌·단순화 정도만 남기고 전체 부피 표현은 렌더링·채색으로 이동 |
| 얼굴 · 가챠 애니 | 큰 눈·홍조·layered highlights가 섞임 | 큰 눈과 홍조는 설계표, 반사광은 조명 담당으로 분리 |
| 얼굴 · CGI 이상화 | East Asian 등 인종 지시가 포함됨 | 인종은 설계표로 이동하고 이상화·얼굴 구조만 남김 |
| 채색 · 보이는 붓질 | `never rendered or photographic` 같은 부정문 | 피하려는 표면 표현을 구체화해 avoid에 저장하고 조합 충돌 확인 |
| 채색 · 셀~그라데이션 | 머리카락의 빛과 3D 금지 문구가 포함됨 | 빛 묘사를 분리하고, 부정 지시는 해당 부품의 avoid에 저장 |
| 채색 · 포토리얼 CGI | 선화·왁스 질감 등의 금지 문구 | 긍정적인 표면 묘사는 본문, 금지 사항은 avoid로 분리 |
| 빛 · 깊은 명암·밝은 자연광 | matte painted surfaces 등 재료·표면 지시 | 표면 성격은 렌더링·채색으로 이동 |
| 빛 · 강한 방향광 | matte paint texture가 포함됨 | 재료·질감 문구를 렌더링·채색으로 이동 |
| 빛 · 하이키 파스텔·시네마틱 하이키 | never·no로 시작하는 부정 지시 | 해당 부품의 avoid로 이동하고 다른 축과의 충돌 검사 |
| 조합 · semi_paint_jp | 유화풍 이름과 실제 채색 문구가 불일치 | 유화 부품을 선택하거나 이름을 붓 터치 페인팅 등으로 변경 |
| 이펙트 · 없음 | 빈 문장으로만 구성됨 | 미지정과 명시적인 없음을 구별 |

문화권을 새로 넣거나 작품 용도를 바꾸는 작업은 단순히 문구를 옮기는 것과 구별한다. 여러 요소를 함께 바꾼 전후 결과를 특정 단어 하나의 효과로 해석하지 않는다.

## 5. 캐릭터·공통 프롬프트 점검

부품만 정리해도 공통 문구에 남아 있는 화풍 지시가 결과에 영향을 줄 수 있다. 현재 시험 대상인 문앙·무협을 기준으로 다음을 먼저 점검한다.

1. **눈 묘사의 내부 모순**: 문앙 설계표에 `smaller, narrower eyes`와 `large round eyes`가 함께 있다. 원하는 디자인을 기준으로 하나의 일관된 묘사로 정리한다.
2. **얼굴 비율의 중복**: `faceFrame`에 얼굴 크기·턱·눈 크기를 고정하는 문구가 있다. 캐릭터 설계와 얼굴 표현 축의 역할을 대조한다.
3. **공통 머리말의 매체 지정**: `character card illustration`이 공통 머리말에 있다. 사진·CGI까지 비교할 때는 이 표현이 시험 대상 매체와 충돌하는지 확인한다.
4. **고정 조건 유지**: 문앙·무협·구도·의상·실제 나이·생김새를 기준 조건으로 고정한다. 변경한 경우 새 기준으로 기록한다.

## 6. 조합 제한과 버전 관리

### 6.1 조합 상태를 구별한다

현재 `only` 방식은 허용 목록 밖의 조합을 막는다. 탐색 목적에 맞게, 실제 모순과 미검증 조합을 구별하는 방향을 권장한다.

| 상태 | 판정 기준 | 처리 방향 |
|---|---|---|
| 충돌 | 같은 대상에 선화 있음과 선화 금지를 동시에 지정하는 등 명시적 모순 | 조립 전에 해결 |
| 검증 전 | 문구에 명시적 모순은 없지만 결과를 아직 확인하지 않음 | 실험 가능 |
| 추천 | 실제 결과를 보고 잘 맞는다고 평가함 | 기본 선택에서 우선 제시 |

유화 질감과 애니식 얼굴처럼 시험할 가치가 있는 조합을 미검증이라는 이유만으로 차단하지 않는다.

### 6.2 기록을 보존한다

현재의 프롬프트 원문·해시 저장과 부품 버전 구조는 유지한다. 다음 기록을 함께 보존하는 방향을 권장한다.

- 부품의 영어 문장과 avoid.
- 그 판에 대응하는 한글 표시 이름과 호환 규칙.
- 실제로 조립한 부품과 각각의 판.
- 조립기와 캐릭터 복사본의 버전 또는 변경 식별자.
- 최종 프롬프트 원문과 해시.
- 사용한 생성 경로·확인 가능한 모델 정보·생성 조건·반복 번호.

검토 당시 한글 이름 `ko`와 호환 규칙 `only`는 문장 버전 바깥에 있었다. 해당 정보를 바꾸더라도 옛 그림의 이름과 조합 조건을 추적할 수 있게 보완한다.

## 7. 실제 이미지 생성 테스트 순서

### 7.1 기준 정리

문앙·무협의 공통 문구를 정리하고, 캐릭터·의상·구도·나이·생김새를 고정한다. 새 다섯 축에 맞는 기준 조합을 만든다.

### 7.2 한 축씩 비교

기준 조합에서 한 축만 교체한다. 이 비교가 보여주는 것은 해당 부품 묶음의 효과다.

붓질 하나의 영향만 알고 싶다면 렌더링·채색 부품 전체를 바꾸지 않고, 붓질 문구만 다른 두 시험안을 비교한다.

### 7.3 필요한 조합만 반복

유망하거나 판단이 애매한 조합만 같은 문구로 2~3회 생성해 본다. 한 장에서 우연히 좋아 보인 특징과 반복해서 나타나는 특징을 구별한다.

### 7.4 작은 교차 비교

남은 후보를 대상으로 두 축의 상호작용을 확인한다. 예를 들어 나라 두 종류와 얼굴 표현 두 종류를 교차하면 다음 네 조합이 된다.

| 조합 | 방향 | 얼굴 표현 |
|---|---|---|
| A | 한국 | 얼굴 1 |
| B | 일본 | 얼굴 1 |
| C | 한국 | 얼굴 2 |
| D | 일본 | 얼굴 2 |

이를 통해 나라 이름의 영향이 얼굴 부품에 따라 달라지는지 확인한다. 같은 방식으로 얼굴 표현×렌더링, 렌더링×조명도 선별해 비교할 수 있다.

### 7.5 평가 항목

| 항목 | 기록할 내용 |
|---|---|
| 취향 | 결과가 얼마나 마음에 드는가 |
| 의도한 특징의 반영 | 바꾼 부품이 요구한 특징이 드러났는가 |
| 캐릭터 유지 | 고정한 얼굴·머리·의상·체형이 유지됐는가 |
| 다른 특징의 변화 | 바꾸지 않은 얼굴·채색·조명 등도 함께 변했는가 |
| 반복 시 유지 | 같은 문구로 반복했을 때 특징이 얼마나 유지됐는가 |

## 8. 문구 조립 예시

아래는 방향·얼굴 표현·렌더링의 담당 범위를 보여주는 부분 예시다. 캐릭터·의상·장면·조명·이펙트·제약을 포함한 전체 생성 프롬프트는 아니다.

```text
Japanese fantasy game key art.
An idealised, recognisably drawn face with gently simplified anatomical structure.
Digital painting: softly modelled volumes, blended shading, subtle brushwork, controlled edges, and distinct surface treatment for silk, metal, and leather.
```

각 부품의 문장을 고정해 조립하고, 변경 시 해당 부품의 판을 올린다. 얼굴·채색·빛을 설명하는 말을 방향 문장에 다시 추가하지 않는다.

## 9. 반영 우선순위

1. 문앙·무협 공통 문구의 모순과 중복 정리.
2. 다섯 축의 담당 범위와 표시 이름 확정.
3. 기존 부품을 새 담당 범위에 맞춰 수정하고 새 판 추가.
4. 미지정·없음, avoid 교체, 조합 충돌 처리 정리.
5. 표시 이름·호환 규칙·생성 조건의 기록 보완.
6. 기준 조합에서 한 축씩 비교한 뒤, 필요한 반복·교차 비교 진행.
