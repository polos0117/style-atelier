# shared — 공방들이 같이 쓰는 파일

사용자 2026-11-24/25 코드 손질 → 「추천 순서대로 1번부터 진행해줘」 4번. 여러 공방이 같은 파일을 손으로 옮겨 쓰다 보니, 한 저장소에만 고친 것이 들어가고 사본이 소리 없이 어긋났다(일상컷 트리 모듈 · 채우기 화면 · 첫 화면). 낱말 블록을 `core/` 한 곳에서 맞추듯, 통째로 같은 파일은 여기 한 곳에서 맞춘다.

- `lib/…` — **원본**. 공방 사본은 이것과 바이트까지 같다. 고칠 땐 여기서 고치고 옮긴다.
- `manifest.json` — 파일마다 `src`(여기 경로) · `dest`(공방 안 경로) · `ateliers`(쓰는 공방). 받는 쪽은 옆 폴더 이름 — 공방(`*-atelier`) · 건담(`atelier`) · 공방 모음(`polos0117.github.io`). 자리가 다른 곳은 `dests: {이름: 경로}` 가 `dest` 를 덮는다(공방 모음은 뿌리에 `favorites.js` · `fill-core.js`).
- `sync.cjs` — 옮기기 · 대조.
  - `node shared/sync.cjs` — manifest 의 공방 전부(옆 폴더 `../<공방>`, 없는 폴더는 건너뜀)에 원본을 쓴다
  - `node shared/sync.cjs ../pkm-atelier ../city-atelier` — 그 공방만
  - `node shared/sync.cjs --check` — 쓰지 않고 다른 사본만 찍는다(다르면 1로 끝남)
- 대조 검사는 여기 `node tests/shared.cjs` 하나(공방마다 검사를 두지 않는다 — 「검사는 바꾼 만큼만」). 옮긴 뒤엔 그 파일을 쓰는 공방의 검사(일상컷 트리 · 계획기 · 지시문 · 화면)를 돌리고 공방마다 커밋한다.

`core/`(낱말)와 다른 점: core 는 공방 파일 끝에 블록을 덧대고 공방에 있는 열쇠만 덮지만, 여기는 **파일 통째**다. 그래서 공방마다 다른 규칙은 코드에 두지 않고 그 공방 표(data/…)에 둔다 — 모듈은 표가 있으면 따르고, 없으면 안 거른다.

- **포켓몬 버전2 갈래 → 표로**: 포켓몬 사본에만 있던 「가슴 위 · 얼굴 클로즈업엔 두 손을 다 올리지 않는다(why code `raised`, 2026-11-09)」 를 코드에서 빼고 표 `raise_one { frames, zones }`(포켓몬 `data/casual-tree-v2.json`)로 옮겼다. 공용 모듈은 이 표가 있을 때만 거른다 — 포켓몬 동작은 그대로(계획기 · 랜덤 · 고르기 지문 같음), 다른 공방은 표가 없어 그대로.
- **게임 · 책 · 신화는 버전2 에서 뺐다**: 옛 사본(2026-11-02 무렵)에서 갈라진 뒤 공용 모듈에 쌓인 규칙(소품 동작 · 뒷모습 돌아보기 손 줄 · 카메라 자세 계열 …)이 그 공방 검사기(`tools/casual-tree-v2.py`)와 지시문 검사(`prompt-game` 의 뒷모습 손 줄)와 어긋난다 — 파일만 바꾸면 안 되고 검사기 · 표 · 검사를 같이 옮겨야 하는 일이라 따로 정할 때까지 옛 사본 그대로. 버전1(`casual-tree.js`)은 더한 함수(`animals`) 하나뿐이라 같이 맞춘다(계획기 출력 같음).
- **꽉 채우기 몸통 · 즐겨찾기(2026-11-25)** — 사용자 「그 우리 가로보기랑 크게보기 만든거 이거를 공방허브에 즐겨찾기 모음해놓은곳에도 적용해줘. 그리고 즐겨찾기 모음은 최대 한도가 500장인건가?」. 공방 모음 즐겨찾기 크게 보기는 preact 가 없어 `fill-view.js`(훅)를 그대로 못 쓴다 — 셈(`fitBox` · `wide` · `MARGIN`)과 두 번 누르기(`makeTap`)를 `fill-core.js` 로 떼고, 훅은 그것을 가져다 쓰며(동작 같음 — 네 공방 `tests/fill-view.cjs` 통과), 공방 모음은 `attach(칸, …)` 로 붙인다. 즐겨찾기는 공방 모음 `favorites.js` 가 원본이던 것을 여기로 옮겼다(아홉 사본이 같았다) — 3000칸, 가득이면 거절 · `error()` · `message()` · `room()`. 대조 · 가득 · 저장 공간 검사는 `node tests/shared.cjs`.
- 넣지 않은 것: 도시 `lib/pixi.js`(도시만 씀), 원소는 pixi 를 `lib/walk-fx.js` 로 부른다.
