# shared — 공방들이 같이 쓰는 파일

사용자 2026-11-24/25 코드 손질 → 「추천 순서대로 1번부터 진행해줘」 4번. 여러 공방이 같은 파일을 손으로 옮겨 쓰다 보니, 한 저장소에만 고친 것이 들어가고 사본이 소리 없이 어긋났다(일상컷 트리 모듈 · 채우기 화면 · 첫 화면). 낱말 블록을 `core/` 한 곳에서 맞추듯, 통째로 같은 파일은 여기 한 곳에서 맞춘다.

- `lib/…` — **원본**. 공방 사본은 이것과 바이트까지 같다. 고칠 땐 여기서 고치고 옮긴다.
- `manifest.json` — 파일마다 `src`(여기 경로) · `dest`(공방 안 경로) · `ateliers`(쓰는 공방).
- `sync.cjs` — 옮기기 · 대조.
  - `node shared/sync.cjs` — manifest 의 공방 전부(옆 폴더 `../<공방>`, 없는 폴더는 건너뜀)에 원본을 쓴다
  - `node shared/sync.cjs ../pkm-atelier ../city-atelier` — 그 공방만
  - `node shared/sync.cjs --check` — 쓰지 않고 다른 사본만 찍는다(다르면 1로 끝남)
- 대조 검사는 여기 `node tests/shared.cjs` 하나(공방마다 검사를 두지 않는다 — 「검사는 바꾼 만큼만」). 옮긴 뒤엔 그 파일을 쓰는 공방의 검사(일상컷 트리 · 계획기 · 지시문 · 화면)를 돌리고 공방마다 커밋한다.

`core/`(낱말)와 다른 점: core 는 공방 파일 끝에 블록을 덧대고 공방에 있는 열쇠만 덮지만, 여기는 **파일 통째**다. 그래서 공방마다 다른 규칙은 코드에 두지 않고 그 공방 표(data/…)에 둔다 — 모듈은 표가 있으면 따르고, 없으면 안 거른다.
